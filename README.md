# 🏓 Sistema de Análise de Desempenho no Tênis de Mesa

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma aplicação web para registrar, acompanhar e analisar o desempenho de jogadores de tênis de mesa.

O objetivo é utilizar a tecnologia para transformar informações de partidas em dados organizados, permitindo acompanhar resultados, consultar estatísticas e identificar oportunidades de melhoria no desempenho esportivo.

Além da aplicação esportiva, o projeto tem como finalidade colocar em prática conhecimentos de programação Python, desenvolvimento web e banco de dados.

## 🚀 Tecnologias utilizadas

- **Python:** linguagem principal do projeto.
- **Flask:** framework utilizado no desenvolvimento web.
- **MySQL:** armazenamento e gerenciamento dos dados.
- **HTML/CSS:** estrutura e apresentação das páginas.
- **OpenPyXL:** geração de arquivos Excel.
- **Git/GitHub:** versionamento do código-fonte.

## ⚙️ Funcionalidades

O sistema contempla o desenvolvimento das seguintes funcionalidades:

- Cadastro e gerenciamento de jogadores.
- Registro de partidas de tênis de mesa.
- Armazenamento de jogadas e resultados.
- Consulta de estatísticas individuais.
- Acompanhamento do desempenho esportivo.
- Exportação de dados para planilhas Excel.
- Área administrativa para gerenciamento das informações.

## 🗄️ Estrutura do banco de dados

O projeto utiliza um banco de dados relacional MySQL, organizado em quatro entidades principais:

| Tabela | Descrição |
|---|---|
| jogador | Armazena informações dos jogadores. |
| partida | Registra as partidas realizadas. |
| jogada | Armazena informações das jogadas. |
| estatistica | Organiza os dados de desempenho. |

## 💻 Como executar o projeto

**1. Clone o repositório:**

```bash
git clone URL_DO_REPOSITORIO
```

**2. Acesse a pasta do projeto:**

```bash
cd tt-performance
```

**3. Crie um ambiente virtual:**

```bash
python -m venv venv
```

**4. Ative o ambiente virtual (Windows):**

```bash
venv\Scripts\activate
```

**5. Instale as dependências:**

```bash
pip install -r requirements.txt
```

**6. Configure o banco de dados MySQL.**

Configure as credenciais de conexão conforme a estrutura utilizada na aplicação.

**7. Execute a aplicação:**

```bash
python app.py
```

Acesse no navegador:

```text
http://localhost:5000
```

*Observação: os comandos devem ser ajustados caso a estrutura ou o arquivo principal do projeto sejam diferentes.*
